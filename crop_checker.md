# Napari Crop Checking Tool

This documentation is for the crop checking tool that is part of the Vesicle Detection - Synaptic Activation Prediction pipeline. 

This tool launches Napari with an additional side bar to let a user load a folder containing EM image crops alongside an optional clustering output (.npz) file in order to manually check the crops for whether they should be included in the training dataset for the Synaptic Activation Prediction model.

## Installing the tool

The tool is included in the Vesicle Detection repository, along with all of the scripts needed to run the pipeline to generate the training crops that the tool is intended to evaluate.

The repository is hosted on github, and the recommended way to install is using git, to enable easy access to any updates.
For this you will need {git}{https://git-scm.com/} installed. 

1. Open a terminal with git available on your machine
2. Navigate to an appropriate installation folder (e.g. `cd Projects/` )
3. Type `git install git@github.com:NewcastleRSE/VesicleDetection.git` at the command prompt and press enter to begin download from github. You may need to authenticate with git credentials.

If you have any issues with this, please contact frances.hutchings@newcastle.ac.uk or carmelo.calafiore@newcastle.ac.uk

Alternatively, you can install a non-version controlled snapshot of the project if you do not have git access:

1. Navigate to the repository page at https://github.com/NewcastleRSE/VesicleDetection 
2. Click on the green "code" button and select 'Download Zip' from the drop down. 
3. Open the downloads folder and unzip the archive into an appropriate location.

You will then need to activate the virtual environment and install prerequisite packages.




## Running the tool

The tool is written in python and can be launched from a terminal by the following process:

1. Navigate to the folder containing the Vesicle Detection repository (`cd <folder_path>`)

2. Activate the virtual environment `conda activate vesicledetection`

3. Run the tool: `python napari_crop_checker.py`

This should launch Napari with the right hand side toolbar. 


## Using the tool 

The tool is intended for manual checking of machine learning training data for the Synaptic Activation Prediction model. The data is expected to be 3D EM image crops centred on synaptic boutons. The tool expects a folder containing crops with filenames in the format `cluster_X_masked.h5` where X is the cluster ID. These are generated by the output of the clustering pipeline (see https://github.com/NewcastleRSE/VesicleDetection/wiki or the SAP_data_generation.md).

### Main workflow
So the first step is to run the pipeline to generate the data that needs checking, and know the location of the folder containing that data and the clustering npz file. Once you have that, the main workflow for using the tool is as follows:

1. Either type in a path to the folder with your data in the text box next to the 'Select Folder' prompt, OR click on the `Choose directory` button to open a file viewer and select the folder from there.
2. Either type in a path to the clusters npz file in the text box next to the 'Cluster NPZ' prompt, OR click on the `Select file` button to open a file viewer and select the clusters file from there.
3. Once the file and folder are pointing to the correct locations, click the `Initialize Folder` button. This may take a few seconds to run, then a set of four image panels should appear.
4. Scroll through the panels using the scroll bar at the bottom to check the current crop - the panels show different projections of the same 3D image. Look to see whether the cluster covers the bouton and the vesicles in it well. It shouldn't cover more than one bouton. Also, if there is more than one cluster in the same bouton, does the combination of the clusters cover the bouton sufficiently? Additionally, check for any artefacts that might cause problems for the machine learning in the image.
5. Once you have evaluated the crop, in the 'Scoring' section of the toolbar select a rating for the crop from the dropdown menu. 'Unsure' is to mark crops that need a second opinion, Bad marks a crop that will be excluded from training, and 'Good' means the crop will be included in training data. 
6. Optional: you can add Notes in the freetext box adjacent to the 'Notes:' prompt, to record why you have made a decision, or if unsure, what the confusion is. 
7. Optional: if a bouton has more than one cluster covering it, you can record the cluster IDs for all the clusters in the box next to the prompt 'Combine with Clusters'. These need to be comma separated or semi-colon separated e.g. `2,45,6,23` the cluster IDs should show up in yellow at the centre point of each cluster, if an npz cluster file has been found successfully. 
8. Once you are happy with the rating and have recorded any notes and cluster combinations needed, press the `Next Crop` button to load the next image in the folder and then repeat tasks 4-8.


### Addtional options

- If you want to re-evaluate a crop, you can use the 'Prev Crop' button to go back to the previous image
- You can use the 'Toggle Cluster Labels' button to turn off/on the yellow labels for the clusters if they are getting in the way
- The usual Napari transparancy and colour options are available in the top left panel of the viewer, and in the lower left you can change the visibility of the images. By default, the tool will try and load masked and raw images to overlay, so you can turn off and on the mask or change the mask layer transparancy when evaluating the crop.
